
# Quizly - Knowledge Challenge 🎯

## 📌 About the Project

Quizly is a responsive, interactive web-based quiz application developed as part of the InternCircle internship program.

The application allows users to test their general knowledge and basic programming concepts through 10 multiple-choice questions. It provides instant feedback, tracks scores, and displays a final performance summary.

## ✨ Features

- Welcome screen with quiz introduction
- 10 multiple-choice questions
- Four answer options for each question
- Instant feedback for correct and incorrect answers
- Explanations for every answer
- Automatic score calculation
- Progress bar to track quiz completion
- Final results screen with score and percentage
- Performance-based feedback messages
- Restart quiz functionality
- Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

- **HTML5** - Structure of the application
- **CSS3** - Styling, layouts and responsive design
- **JavaScript** - Quiz logic, answer validation and score calculation

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Extract the project files.
3. Open the project folder.
4. Double-click `index.html`.
5. The quiz will open in your web browser.
6. Click **Start the Quiz** and begin answering the questions.

## 🎮 How to Play

1. Click the Start the Quiz button.
2. Read each question carefully.
3. Select one answer from the four available options.
4. View instant feedback and the correct answer explanation.
5. Click Next Question to continue.
6. Complete all 10 questions to view your final score.
7. Click Play Again to restart the quiz.
